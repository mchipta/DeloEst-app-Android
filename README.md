# ДелоЕсть — настоящее Android-приложение (Flutter)

Нативное приложение: экраны рисует Android, не браузер. Дизайн повторяет сайт (цвета, карточки,
нижнее меню, светлая и тёмная тема). Сервер — тот же Google Apps Script, что у сайта,
поэтому аккаунты и объявления общие.

## Что есть (этап 1)
- Лента объявлений: поиск, фильтр «Нужен исполнитель / Предлагаю услуги», категории, обновление свайпом
- Страница объявления: фото с листанием, автор и рейтинг, «Откликнуться», «Позвонить»
- Вход, регистрация с кодом на почту, сброс пароля
- Размещение и редактирование объявления с фото (до 5)
- Кабинет: мои объявления (закрыть/открыть/изменить), отклики мне (выбрать, отклонить, выполнено), мои отклики
- Тёмная тема (кнопка в кабинете)

Дальше: этап 2 (сообщения, профиль, настройки), этап 3 (верификация, push и остальное).

## Как получить APK
1. Создай на GitHub новый репозиторий и загрузи в него всё содержимое этой папки (вместе со скрытой `.github`).
2. Вкладка **Actions** → «Сборка APK» запустится сама (первый раз 8–12 минут).
3. Готовый `DeloEst.apk` — в **Releases**. Скачай с телефона и установи.

Не удаляй `signing/debug.keystore`: по нему Android узнаёт приложение, и новые сборки ставятся поверх старых.
Это отдельное приложение: прежнюю APK-обёртку над сайтом, если ставил, можно удалить.
