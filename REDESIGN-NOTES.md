# ДелоЕсть — нативный Flutter-редизайн

Это **нативное Flutter-приложение**. WebView и открытие сайта внутри приложения не используются.

## Что изменено

- Главный экран перенесён в мобильную Flutter-компоновку: hero-блок с двумя режимами поиска, строка поиска и город, быстрые категории, объявления, категории, шаги, отзывы, FAQ, блок для бизнеса и контакты.
- Цвета и формы приближены к CSS сайта: светлая/тёмная палитры, скругления, границы, кнопки и карточки.
- На ленте объявлений оставлен один вход в фильтры. Тип, категория, город, диапазон оплаты и сортировка находятся в едином меню.
- Кабинет получил 4 вкладки сайта: объявления, отклики мне, мои отклики и настройки. Существующие настройки и управление аккаунтом сохранены.
- В настройках есть имя, почта, телефон, фотография, тема оформления, уведомления внутри приложения, отключение уведомлений по отдельным диалогам и часовой пояс.
- Сообщения, избранное, отклики, публикация и профиль остаются нативными экранами и продолжают обращаться к Google Apps Script.
- Нижняя навигация упрощена до четырёх пунктов: Главная, Объявления, Разместить, Кабинет/Войти.

## Важное про изменения сайта

Это нативная реализация дизайна, поэтому правки CSS/HTML в `index.html` **не меняют внешний вид APK автоматически**. Основные места для дальнейшей доработки:

- `landing.dart` — главная страница и мобильная компоновка сайта;
- `theme.dart` — палитра, карточки, поля ввода и тема;
- `widgets.dart` — карточки объявлений, кнопки, логотип и общие элементы;
- `feed.dart` — поиск и фильтры;
- `cabinet.dart`, `settings.dart`, `messages.dart` — кабинет, настройки и переписки.

Тексты сайта (заголовок, описание, статистика, отзывы, FAQ и контакты) по возможности загружаются через существующий метод `site` Google Apps Script. Сервер `Code.gs` этой сборкой не изменялся.

## Сборка

В существующем репозитории сохранён workflow `.github/workflows/build-apk.yml`, который копирует корневые файлы `*.dart` в Flutter-проект и собирает `DeloEst.apk`.

1. Замените исходники из патч-архива или загрузите полный проект в свой репозиторий.
2. Отправьте изменения в ветку `main`.
3. Откройте GitHub → Actions и дождитесь завершения workflow.
4. Скачайте артефакт `DeloEst-apk`.

В этой среде Flutter SDK отсутствует, поэтому локальная сборка APK и `flutter analyze` не выполнялись. Перед использованием проверьте результат GitHub Actions.
